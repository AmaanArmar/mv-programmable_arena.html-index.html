# Programmable Arena

A 10×10 grid combat game where players program robots with simple move & shoot commands. All bots execute their instructions simultaneously.

## How to Play
1. Choose 2–4 players
2. Each player builds a queue of up to 10 actions (Forward / Back / Left / Right + Shoot)
3. Press **Done → Next**
4. When everyone is ready, press **▶ RUN ROUND**
5. Watch the bots move and fight at the same time

## Features
- 10×10 grid with obstacles
- Smooth movement & facing direction
- Simultaneous execution
- Score tracking and rankings
- Pure HTML / CSS / JavaScript (no dependencies)

Open `index.html` in any modern browser to play locally.
